# TALINBUILDS House Style

**GOVERNANCE:** This file governs TALINBUILDS-owned properties ONLY (his own site, pitch decks, outreach materials). It is NEVER applied to a client build. Every client site still derives its own bespoke palette and type trio per Phase 3 of the master skill. Reusing a fixed house style on every client is the exact mistake that makes agencies look like templates.

## The Banned-Look Carve-Out

Near-black plus green is on the AI-cliché ban list. We earn it three ways:
1. The green is Brunswick and Emerald sampled from the Monestra board, not acid.
2. The signature element (footnote ledger) is structural, not decorative.
3. The layout skeleton is a ledger, not a SaaS stack.

## Tokens

```css
:root{
  --canvas:#0B0F0D;      /* The board's near-black green, never pure black */
  --panel:#0C4137;       /* Brunswick Green, cards and raised surfaces */
  --panel-soft:#12382F;  /* Brunswick lifted one step for hovers */
  --ink:#E6FBF6;         /* Polar, primary text */
  --ink-soft:#A9C8BD;    /* Polar dimmed, secondary text */
  --accent:#06D6A0;      /* Emerald, CTA and rare emphasis only */
  --accent-hover:#39FF9B;/* Legacy cursor green, hover and caret only */
  --foil:#B08D57;        /* Aged brass, ONE Old Money foil: folio numerals, rule lines */
}
```

The emerald-to-Brunswick gradient is allowed in exactly two places: the hero artifact and one CTA hover glow. Never as a section background.

## Type Trio

Display: Cormorant Garamond (600, 700, italic for emphasis). Gothic elegance, high contrast, Old Money.
Body: Source Sans 3 (400, 600). Quiet, proven.
Labels: IBM Plex Mono (400, 500). Folio numerals, receipts, tags.
Scale: H1 at 72px minimum on desktop. Weight contrast at least 3x body.

## Signature Element: The Footnote Ledger

Every claim on the site carries a superscript folio number. A right-rail or bottom rail lists the footnotes as receipts: measured load times, build dates, tools used, "200+ sites built since 2023, pre-AI".
The Test: Remove the ledger. If the page loses its proof structure, it passes the signature test.

## Supporting Motifs

Brass hairline rules that draw themselves on scroll, mono folio numerals per section ("fol. 01"), and the emerald caret that underwrites link hovers.

## Section Map (Seven Blocks, No Two Adjacent Skeletons Alike)

Hero Manifesto (Mode S): One line + caret + one CTA ("See the work").
The Ledger of Work: Case cards with folio numbers and speed receipts.
Method (Three Movements): Listen, Build, Keep (Face/Work/Growth renamed).
Pricing: Anchor order deliberate. Premium tier first (contrast effect), Basic last. 50% upfront stated in the section itself.
Proof: Footnote rail promoted to a section + two client-language quotes.
About (Craft Ledger): 19, Nalasopara, 200+ sites, the abroad plan stated plainly.
Contact: WhatsApp CTA, one field, smart default ("Clinic or salon? I'll send the right example").

## Hero Concepts

### A (Recommended): "Ink Ledger."

Emerald ink pours onto near-black paper, spreads into ruled ledger lines, settles on the wordmark with the caret blinking. Forgiving subject (fluid/light), vertical axis, composed resting ending. Mode S, one image + one video, trial-credit friendly.

### B: "Study Diorama."

Mode W two-scene teaser. Miniature desk world (laptop, ledger, cup) flown through. Charming, ~3x credits, doubles as lets-scroll proof piece. Build second, use as Premium tier sales demo.
